# Почему так

Книга Сергея Отческова о дизайне. Для тех, кто делает сайты, упаковки и презентации, и для тех, кто просто сталкивается с ними каждый день.

Здесь хранятся рукопись, правила, обсуждения и история правок. Название принято автором. Последняя редакция предисловия и первых двух глав передана ему на чтение; окончательного одобрения текста пока нет.
