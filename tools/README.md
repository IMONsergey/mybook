# Сборка рабочих файлов

Текущий Word перенесён в репозиторий из уже проверенной редакции v3 без изменений. Скрипт сборки адаптирован к относительным путям этого репозитория.

## Зависимости

Python 3.10 или новее. Проверенная сборка выполнена с python-docx 1.2.0 и Pillow 12.3.0; версии записаны в requirements.txt. Для точного повторения внешнего вида Word нужны Georgia и Arial. Без них просмотрщик может подставить другие шрифты и изменить переносы страниц.

```bash
python -m pip install -r requirements.txt
python tools/update_preview.py
python tools/build_docx.py
```

Первый скрипт обновляет manuscript/README.md из manuscript/source.md. Второй сохраняет Word в exports/current/Почему_так_главы_1_2.docx. Чтобы собрать проверочную копию, передать другой путь:

```bash
python tools/build_docx.py --output /tmp/book-review.docx
```

Сборка не выполняет рендер и визуальную проверку автоматически. После изменения рукописи проверить весь Word в установленном редакторе либо через доступный конвертер в PDF и изображения страниц. До такой проверки новый файл не считать готовым к передаче.

assets/figures/build_figures.py содержит код построения учебных рисунков. Готовые PNG уже хранятся в репозитории, поэтому для обычного редактирования текста пересобирать их не нужно.

## Проверка целостности книги

`python3 tools/book_audit.py` читает источник и изображения без изменения рукописи. `--output research/audit-v3-2026-11-01.json` сохраняет отдельный отчет. Pillow нужен для проверки изображений. Код завершения 1 означает ошибки целостности, 0 допускает предупреждения, требующие редакторской проверки.

`python3 -m unittest discover -s tools -p 'test_book_audit.py' -v` запускает тесты на временных материалах. Скрипт проверяет маркеры, файлы, размеры, alt, записи прав, повторы и выбранные символы. Он не проверяет юридическую действительность прав, литературное качество или готовность печатного PDF.

Счет слов исключает целиком маркеры FIGURE вместе с подписями и Markdown-знаки заголовков; заголовки и имя автора входят. Для заявки издателю использовать отдельный согласованный способ счета.
