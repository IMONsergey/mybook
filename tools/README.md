# Сборка текущей редакции

Текущий источник: manuscript/source.md. Предыдущий build_docx.py оставлен как историческая утилита v3; для v4 использовать build_docx_v4.py.

## Word и читаемая версия

Зависимости: requirements.txt. В системе должны быть доступны PT Serif и IBM Plex Sans с кириллицей. Подмена шрифтов меняет переносы и число страниц. Рендерер с отдельным профилем пользователя должен видеть шрифты на системном уровне.

```bash
python tools/update_preview.py
python tools/build_docx_v4.py
```

Результат: exports/current/Почему_так_первые_пять_глав_v4.docx. Формат 180 × 250 мм, PT Serif 11,5 пункта, интерлиньяж 15 пунктов, заголовки IBM Plex Sans. Оглавление берет номера из exports/current/toc-v4.json. После изменения текста обновить номера по фактическому рендеру и пересобрать документ. Перед передачей проверить все страницы.

## Иллюстрации

Четыре сгенерированных PNG уже сохранены. Для пересборки десяти схем поместить шрифты, указанные в assets/fonts/README.md, в assets/fonts/ или задать BOOK_FONTS. Запустить python tools/build_visuals_v4.py. Этот скрипт создает PNG и diagrams-v4.json с редактируемыми элементами. Сведения о генерации сцен: assets/photos/generation-v4.json.

## Figma

Текущие идентификаторы страниц и разворотов: exports/current/figma-v4.json. Геометрия и текст: exports/current/layout-v4.json. export_figma_v4.py извлекает их из проверочного PDF в render_final/ и требует PyMuPDF. PDF и изображения рендера нужны для проверки и не входят в пользовательский комплект. Figma собирается из редактируемых текстовых блоков, элементов схем и четырех растровых сцен. После изменения рукописи обновить обе версии и заново проверить переносы.

## Техническая проверка

python tools/book_audit.py проверяет целостность источника, маркеры, файлы, alt, записи прав, повторы и выбранные символы. Она не подтверждает литературное качество или готовность к печати. Проверка v4: 0 ошибок и 14 предупреждений о незавершенной издательской проверке прав. Счет слов исключает маркеры FIGURE вместе с подписями, но включает заголовки и имя автора.
