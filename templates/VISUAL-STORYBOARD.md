# Сценарий визуального разбора

- ID и глава:
- Вопрос читателя:
- Что изображение сообщает самостоятельно:
- Что добавляет текст:
- Что одинаково в сравниваемых вариантах:
- Что меняется:
- Какие выводы по этому изображению сделать нельзя:
- Реальный объект или учебный пример:
- Источник и статус прав:
- Редактируемый оригинал:
- Размер размещения и эффективное разрешение:
- Подпись:
- Alt-текст и при необходимости расширенное описание:

| Шаг | Что видит читатель | Что меняется в понимании | Требуемый масштаб | Связь с текстом |
| --- | --- | --- | --- | --- |
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

Проверить на распечатке 1:1 и на узком экране. Подписи, тонкие линии и мелкий текст должны оставаться читаемыми. Направление чтения понятно без объяснения автора. Цвет не является единственным носителем различия.
