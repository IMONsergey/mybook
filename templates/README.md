# Рабочие шаблоны

Скопировать нужный шаблон в материалы конкретной главы или заявки. Пустые поля не заменять вымышленными сведениями. Сами шаблоны остаются исходной формой.

| Шаблон | Когда применять |
| --- | --- |
| [Карточка главы](CHAPTER-BRIEF.md) | До написания или структурной переработки |
| [Заявка издателю](PUBLISHER-PROPOSAL.md) | После выбора канала; готовые формулировки внутри являются предложениями |
| [Читательская проверка](READER-TEST.md) | Когда есть фрагмент, который можно читать без пояснений автора |
| [Визуальный сценарий](VISUAL-STORYBOARD.md) | Перед версткой разворотов |
| [Приемка страницы и разворота](PAGE-REVIEW.md) | После компоновки и после изменений; отдельно техническое качество, выразительность и одобрение автора |
| [Задание на производство](PRODUCTION-BRIEF.md) | До подтверждения печатной готовности |

## Реестры

[research/claims.csv](../research/claims.csv) хранит точное утверждение, место, тип, источник, основание и статус. Первые четыре записи показывают разные типы утверждений текущего пилота; это не полный фактчекинг книги. `author_impression` означает личную реакцию, `observable_layout` видимый признак, `evidence_limit` ограничение доказательств, `fictional_example` учебную ситуацию. Для новых эмпирических тезисов добавлять первичный источник и конкретное место в нем.

[assets/rights.csv](../assets/rights.csv) хранит происхождение каждого изображения. `unverified` означает, что подтверждение еще не оформлено. `author_confirmed` допустимо после подтверждения автора; `cleared` после записи достаточного основания, разрешения или подходящей лицензии. Нельзя менять статус только для исчезновения предупреждения скрипта. Лицензии шрифтов учитывать отдельно от прав на композицию.
