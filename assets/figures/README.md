# Иллюстрации

Шесть учебных сравнений, подготовленных для первых двух глав. Вымышленные события, упаковки и интерфейсы используются как примеры; они не являются клиентскими кейсами Сергея.

| Порядок в v3 | Файл | Что показывает |
|---|---|---|
| 1 | fig01_voice.png | «Вход со двора» в трёх оформлениях |
| 2 | fig02_poster.png | Одинаковые сведения об одном событии с разной иерархией |
| 3 | fig03_context.png | Афиша события и указатель к залу |
| 4 | fig05_wrappers.png | Две упаковки одного вымышленного шоколада |
| 5 | fig04_neighbours.png | Два эскиза приглашения «Ближе» |
| 6 | fig06_empty_state.png | Пустой результат поиска без действия и с действием |

Нумерация исходных файлов отражает первоначальную редакцию. Порядок рисунков в текущей рукописи другой: шоколад идёт перед приглашением. Не переставлять их автоматически по имени файла.

Подписи актуальной редакции находятся в manuscript/source.md. manifest.json хранит размеры и альтернативное описание изображений. Программа build_figures.py сохраняет исходную логику их построения; для запуска нужны Pillow и шрифты DejaVu по пути, указанному в программе.

Важная правка разбора «Ближе»: тесные формы показывают сближение, но тяжёлые полосы могут выглядеть как перегородка. Текст v3 прямо обсуждает эту слабость эскиза. Нельзя возвращать безоговорочную оценку иллюстрации как удачного приглашения.
